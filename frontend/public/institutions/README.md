# Logos de organismos

Los logos de las instituciones deben estar en esta carpeta. Las tarjetas buscan los siguientes archivos:

- `PDVSA-Logo.wine.png` — PDVSA Petróleo, S.A.
- `Ministerio del Poder Popular para la Salud (MPPS).jpg` — Ministerio del Poder Popular para la Salud (MPPS)
- `Metro de caracas.jpg` — C.A. Metro de Caracas
- `Cantv_logo.png` — CANTV - Telecomunicaciones
- `ministerio-del-poder-popular-para-la-alimentacion-logo-png_seeklogo-246331.png` — Ministerio del Poder Popular para la Alimentación

Los nombres distinguen mayúsculas, espacios y extensión; conserva el nombre exacto al reemplazar una imagen. Se recomienda usar PNG o WebP cuadrado, con fondo transparente y tamaño de 256 × 256 píxeles. Si el logo no está disponible o el archivo no carga, se mostrará un icono de institución de reserva.
