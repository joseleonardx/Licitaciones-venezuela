# Logos de organismos

Coloca aquí los logos de las instituciones. Las tarjetas los mostrarán junto al nombre del organismo si el archivo coincide con uno de estos nombres:

- `pdvsa-petroleo-sa.png` — PDVSA Petróleo, S.A.
- `mpps-salud.png` — Ministerio del Poder Popular para la Salud (MPPS)
- `metro-de-caracas.png` — C.A. Metro de Caracas
- `cantv-telecomunicaciones.png` — CANTV - Telecomunicaciones
- `ministerio-alimentacion.png` — Ministerio del Poder Popular para la Alimentación

Se recomienda usar PNG o WebP cuadrado, con fondo transparente y tamaño de 256 × 256 píxeles. Si el logo no está disponible o el archivo no carga, se mostrará un icono de institución de reserva.
